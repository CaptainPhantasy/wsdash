# Floyd's Labs — instrument workshop identity

The mark turns one input into useful paths. A measured square frame holds an open prism: a nod to Floyd's music history, drawn as a working instrument rather than a record-cover imitation. The frame suggests a workshop jig; the beam suggests a builder turning an idea into a tool.

The light and dark marks use exactly the same paths. Ink `#101318`, warm ivory `#f3eee3`, signal amber `#ffba49`, and sea-glass cyan `#80cdc4` form the palette. On light surfaces, the beam accents deepen to `#935400` and `#286a65` for readable contrast. The essential frame and prism remain recognizable in one color. The small composer/favicon version removes the frame and keeps the prism and two beams.

Product cards use DIN Condensed for tall industrial titles, Noto Sans for the benefit, and Source Code Pro for small instrument labels. Every visible letter is an SVG path; the assets need no installed fonts or network resources. These fonts are used only to draw text: no font files are distributed in the brand kit. Cards share a measured border, ruler, and quiet product-specific illustration. The maze explores another route; the five tool slots organize busywork; the terminal opens space; the workspace stack finds a thread; the receipt sheet asks for evidence.

Copy is direct, useful, and grounded in the garage. The cards reproduce the supplied product benefits and brief descriptions. They contain no release badge, customer metric, benchmark, or invented capability. The illustration is an imagined garage scene, not a photograph of Floyd's actual workshop.

Use the dark wordmark on ink surfaces and the light wordmark on ivory surfaces. Keep logos at least 32 px; use the composer icon for favicon-sized surfaces. Preserve square corners and leave at least a quarter of the mark width clear around it. The square SVG marks have transparent backgrounds. The composer icon is a complete ink tile.

The 1200 × 630 card SVGs are the editable vector masters. PNG and JPEG siblings are supplied for social previews and README image compatibility. Use the JPEG as `assets/hero.jpg` under the existing release pattern when needed. Each is a static marketing card, not a product screenshot.
